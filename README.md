# 🌿 WildPhytoDB

Cold-region Wild Plant Secondary Metabolite Database

## 🔬 项目简介
一个用于研究冷域野生植物次生代谢物的开源数据库项目。

## 🚀 功能
- 植物数据库（species）
- 代谢物（metabolites）
- 功效（effects）
- 关系建模

## 🧬 技术
- Supabase (PostgreSQL)
- SQL
- GitHub Pages

## 📦 使用方法

1. 在 Supabase 执行：
   - schema.sql
   - seed.sql

2. 打开 web/index.html

## 🌍 应用方向
- 药物研发
- 功能食品
- 生物信息学
