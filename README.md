# 🌿 WildPhytoDB

Cold-region Wild Plant Secondary Metabolite Database

## 🔬 项目简介
一个用于研究冷域野生植物次生代谢物的开源数据库项目。

## 🚀 功能
- 植物数据库（species）
- 代谢物（metabolites）
- 功效（effects）
- 关系建模

# 🌿 WildPhytoDB

## Overview
Cold-region plant metabolite research platform.

## Features
- Database (Supabase)
- Web interface
- Statistical analysis
- Automated report generation

## Usage
1. Run database/schema.sql
2. Run database/seed.sql
3. Open web/index.html
4. Run analysis/report.py

## Output
- Figures
- Report.txt
